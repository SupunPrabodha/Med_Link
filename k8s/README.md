# Kubernetes (minimal)

This folder contains a minimal set of manifests to demonstrate Kubernetes deployment concepts required in `requirements.md`.

**Note:** These manifests are intentionally simple for marking purposes.

## Contents
- `namespace.yml`
- `configmap.yml` (non-secret settings)
- `secrets.yml` (demo secrets)
- `postgres.yml` (StatefulSets)
- `rabbitmq.yml`
- `apps.yml` (Deployments + Services)
- `ingress.yml`
